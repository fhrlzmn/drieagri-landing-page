# DrieAgri Landing Page

This is a landing page for a fictional company called DrieAgri, which specializes in agricultural technology.

### Demo

You can view the live demo of the project [here](https://drieagri-landing-page.vercel.app/).

### Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Lucide Icons

### Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
